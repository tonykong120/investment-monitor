# V2.8 上传说明

这版主要做了 3 件事：

1. **视觉风格重做**
   - 改成更接近参考图的浅色、简洁、仪表盘风格
   - 板块更精简，减少大段说明文字

2. **分钟级异动雷达不再空白**
   - 页面第一次拿到实时行情后就立即展示
   - 1/3/5 分钟数据不足时显示“采样中”，不再整块空着

3. **前端实时性加强**
   - 实时行情从约 10 秒缩短到约 5 秒
   - 板块资金尝试每 30 秒前端刷新一次
   - 后台模型仍依赖 GitHub Actions，不是秒级
