# 短线机会工作台 V1.4

新增：
- 今日机会从最多3只提高到最多5只。
- 前台不再把“触发价”作为主要买点，改为“计划买入区 + 理想价 + 不追价线”。
- 新增历史1/3/5日信号胜率。
- 5日胜率口径：历史同类技术结构出现后，未来5个交易日内 +3.5% 目标先于 -2.5% 止损触发。
- 同日同时触发目标和止损按止损处理，采用保守口径。
- 显示历史样本数和可信度；少于6次标记样本不足。
- 技术触发价仍保留在“后台技术触发条件”折叠区。

## 上传
覆盖：
- index.html
- scanner.py
- .github/workflows/scan.yml

然后 Actions → Refresh market scan → Run workflow。

注意：历史胜率是样本统计，不是未来承诺或真实预测概率。
