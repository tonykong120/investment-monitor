# 短线机会工作台 V1.6 — 待涨判断版

新增核心指标：

## 1. 待涨指数（0-100）
用于判断“现在这个位置买进去以后，1~5个交易日继续上涨的结构强不强”。

综合：
- 当前技术综合分 35%
- 历史相似信号5日上涨率 27%
- 历史目标胜率 13%
- 当前市场环境 18%
- 资金评分 7%

进入计划买点区会获得轻微加分。

等级：
- >=72：待涨强
- 64~71.9：偏强
- 56~63.9：中性偏多
- 48~55.9：一般
- <48：偏弱

注意：待涨指数是模型强弱评分，不等于真实概率。

## 2. 5日上涨估计
统计该股历史相似结构后，第5个交易日收盘价高于信号日的比例。
为了避免小样本出现虚假的80%、100%，会按样本量向50%中性值收缩。

## 3. 目标胜率
仍采用更严格的交易口径：
未来5日内先达到 +3.5%，且没有先触发 -2.5% 止损，才记为一次胜利。

## 4. 更多历史统计
- 1日上涨率
- 3日上涨率
- 5日上涨率
- 1/3/5日平均收益
- 5日平均最大上冲
- 5日平均最大回撤
- 样本数和可信度

## 5. 机会排序
候选股优先按“待涨指数”排序，再按综合分排序。
最多显示5只，并要求待涨指数至少达到56（中性偏多）。

## 更新方式
覆盖：
- index.html
- scanner.py

工作流 scan.yml 与 V1.5 兼容，不强制替换。
然后 Actions → Refresh market scan → Run workflow。
