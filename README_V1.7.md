# 短线机会工作台 V1.7 — 启动初期版

这版针对“机会股基本已经涨了几天”的问题重做选股定义。

## 核心变化

### 1. 已涨过滤器（硬过滤）
以下任一满足，不能进入“买点机会”：
- 近5日累计涨幅 > 8%
- 近10日累计涨幅 > 13%
- 连续上涨 >= 3天
- 当前价高于5日线 > 4.5%
- 当前价高于10日线 > 7.5%
- 处在20日明显高位且波动区间已经大幅扩张
- 当日涨幅 > 4.8%

### 2. 只优先找4种早期形态
- 平台首破
- 回踩确认
- 底部转强
- 首次站回均线

### 3. 新增“早期机会分”
评分重点从“趋势已经很强”改成：
- 形态是否刚启动
- 近5/10日有没有涨太多
- 连涨天数
- 距离5日线
- 20日位置
- 是否首次/温和放量

### 4. 胜率重算
历史回测也只统计“早期形态”。
如果当前形态的历史样本 >= 6，优先用同一种形态回测；
否则才退回全部早期形态样本。

### 5. 买入区重做
不再围绕“向上突破触发价”给买点。
改成：
- 平台首破：靠近突破位回踩
- 回踩确认：靠近5日线
- 底部转强：靠近5/10日线承接区
- 首次站回均线：靠近5日线确认

## 机会池条件
最多5只，但必须：
- 没触发已涨过滤
- 早期机会分 >= 60
- 状态为“早期买点”或“早期观察”
