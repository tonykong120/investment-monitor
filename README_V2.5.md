# 短线机会工作台 V2.5 — 高弹性待涨池

这版针对“卖飞/错过高弹性短波段”增加独立机会池。

## 高弹性待涨池硬条件

- 待涨概率 >= 60%
- 5日弹性空间估计 >= 8%
- 当前进入买点区
- 近5日不能涨太多，连续上涨不能太多
- 换手率不能太低：最近5日均换手或最近有效换手 >= 2%
- 股价 5~30 元
- 主板优先：剔除科创、创业、北交、ST、退市
- 板块/环境不弱：当前先用市场环境分 >= 45 作为免费版代理

## 说明

“5日空间估计”来自历史同类最大上冲与近期ATR/振幅的合成，不是收益承诺。
真正短线仍需执行止损和不追价线。
