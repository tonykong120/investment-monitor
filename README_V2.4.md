# 短线机会工作台 V2.4 — 资金异动反推题材版

这版修正 V2.3 的方向：不是追踪某个新闻事件，而是先扫全市场资金异动，再反推出可能的题材/新闻线索。

## 核心逻辑

资金异动 → 板块/概念聚类 → 成分股资金先动 → 反推可能题材 → 用户再去验证新闻。

## 新增

- 全市场资金异动反推雷达
- 行业 + 概念双层扫描
- 反推可能线索：AI算力、通信/6G、半导体、机器人、低空经济、军工、新能源、医药、金融等
- 资金先动个股列表
- 一键加入自选继续盯盘
- 可选过滤词：留空就是全市场扫描；输入关键词只是辅助验证，不是固定追踪

## 使用方式

1. 上传覆盖 index.html 和 scanner.py
2. data/latest.json 不要手动覆盖
3. GitHub Actions → Refresh market scan → Run workflow
4. 打开网页后点击「扫描资金异动」

## 注意

这里的资金流来自公开资金口径，不代表真实机构身份。它适合做短线雷达和线索发现，不能当成买入保证。
