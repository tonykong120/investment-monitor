# 短线机会工作台 V2.2 — 实时短线雷达版

这版重点解决“数据更新不及时”。

## 关键变化

### 1. 前端实时行情层
页面不再完全等待 GitHub Actions 的 latest.json。
打开网页后，浏览器会直接请求腾讯行情，约 10 秒刷新一次：

- 现价
- 涨跌幅
- 开盘价
- 最高价
- 最低价
- 成交额
- 日内振幅

### 2. 分钟级异动雷达
浏览器会记录自选、机会池和候选池的实时价格快照，计算：

- 1分钟涨跌
- 3分钟涨跌
- 5分钟涨跌
- 5分钟成交额增量
- 日内振幅
- 急拉追高风险

信号包括：

- 分钟强启动
- 放量走强
- 资金承接
- 转弱
- 急拉，不追

注意：打开页面后需要 1-5 分钟采样，分钟数据才会逐步准确。

### 3. 自选监控升级
自选股票会显示实时信号：

- 3分钟涨跌
- 5分钟涨跌
- 5分钟成交额增量
- 实时状态

即使没有进入后台深度候选池，也能看到更完整的实时行情。

### 4. 两层数据结构
- 实时行情层：浏览器约 10 秒刷新
- 模型层：GitHub Actions 定时扫描，更新买点、弹性、胜率、机会排序

## 现实限制

GitHub Pages 不能运行常驻后端，所以不能做到真正 Level-2 实时资金流。
本版能做到的是“行情接近实时 + 本地分钟异动判断”。

真正的实时资金流/板块资金秒级监控，需要部署常驻服务器，并接入稳定行情或付费数据源。
