# 短线机会工作台 V3.1 资金交易台版

## 大改内容

已删除：
- 自选监控主逻辑
- 高弹性池作为独立核心板块

新增/重排：
1. 今日机会：买点、止损、目标、仓位、胜率、K线量价、主力资金、筹码、支撑压力。
2. 板块资金：流入和流出两列。
3. 主力个股：主力资金流入个股。
4. 资金异动：资金承接、潜伏吸筹、冲高兑现。
5. 潜伏个股：涨幅不高但资金/结构改善。
6. 个股诊断：输入 6 位代码，若后台有深度数据则显示交易卡片，否则显示实时行情。
