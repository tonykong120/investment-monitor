# 短线机会工作台 V3.0 稳定架构版

## 核心目标
先恢复稳定，再保留关键实时能力。

## 架构变化
V3.0 把页面拆成三层独立逻辑：

1. 后台模型层
   - 读取 data/latest.json
   - 失败时尝试多个路径
   - 再失败时使用本地缓存兜底

2. 实时行情层
   - 独立拉取腾讯实时行情
   - 只影响实时雷达和自选价格
   - 失败不影响今日机会和后台模型

3. 板块资金层
   - 独立拉取东方财富板块资金
   - 失败不影响其他模块
   - 可回退后台 sector_flow

## 为什么比 V2 稳
- 不再多版本脚本叠补丁
- 单脚本状态管理
- 每层数据互相独立
- 一个模块失败不会拖垮整页
- 数据状态页可查看每层状态

## 页面保留
- 总览
- 今日机会
- 高弹性待涨池
- 板块资金
- 实时雷达
- 自选监控
- 数据状态
