# 短线机会工作台 V2.0 — 波段交易版

## 这版解决的问题
- 机会太少：在不追高的前提下，放宽为高弹性短波段优先，最多 TOP5。
- 只看早期不够：新增短线弹性评分，高弹性优先，适合涨1~2天就撤。
- 自选信息不全：自选未进入深度池时，至少显示现价、涨跌、成交额、开高低、日内振幅、快速弹性。
- 交易记录干扰：已删除。
- 需要板块资金：新增板块资金流看板，显示净流入/净流出板块。
- 需要避免追高：新增“今日不追 / 风险池”。

## 核心模块
1. 今日短线机会 TOP5
2. 自选监控（搜索添加/删除）
3. 板块资金流向看板
4. 候选池 TOP25
5. 今日不追 / 风险池
6. 市场环境与短线建议

## 弹性说明
- 高弹性：适合 1~2 日快进快出，波动大，止损必须明确。
- 中弹性：适合 2~5 日短波段。
- 低弹性：短线效率偏低，不优先。
