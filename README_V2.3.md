# 短线机会工作台 V2.3 — 事件题材资金异动版

新增：事件题材资金异动雷达。

## 解决的问题
新闻出来时，相关股票可能已经提前涨了几天。V2.3 不只等新闻关键词，而是用：

事件关键词 → 产业链扩展词 → 板块/概念资金流 → 成分股资金异动

快速反推资金正在攻击的方向。

## 默认事件模板
英伟达6G：
英伟达、6G、基站、通信设备、通信服务、射频、天线、光模块、CPO、光通信、算力、边缘计算、服务器、交换机、液冷、铜缆高速连接。

## 使用方法
1. 打开页面。
2. 点击“英伟达6G”或输入自己的事件关键词。
3. 点击“扫描资金异动”。
4. 先看事件相关板块/概念，再看成分股异动。
5. 对个股点击“加自选”，再用分钟级异动雷达盯盘。

## 注意
这是公开资金口径，不等同于真实机构账户；可以快速发现方向，但不能替代交易纪律。
