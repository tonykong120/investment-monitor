# V2.12 今日机会增强 + 总览模块拖拽版

## 本版改动

1. 今日机会信息增加
   - 买入区、理想价、不追线
   - 止损、目标1/目标2、盈亏比
   - 待涨估计、待涨等级
   - 5日空间、弹性评分、ATR/振幅
   - 近3/5/10日涨幅
   - 换手、成交额、资金状态
   - 回测样本、5日上涨率、目标胜率、平均收益
   - 信号原因、风险警告
   - 更多细节可展开

2. 总览模块可以拖动排序
   - 今日机会
   - 高弹性待涨池
   - 实时雷达
   - 资金趋势感知
   - 板块资金 Top
   拖动后的顺序会保存在浏览器 localStorage。

3. 总览自适应
   - 使用自动网格布局
   - 宽屏自动两列/多列
   - 窄屏自动单列
